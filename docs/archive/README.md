# Historical development records

These files preserve earlier plans, investigations, delivery records and test
observations. They are not current product documentation, supported behavior,
or a release checklist. Dates, ticket states, paths and constraints may be obsolete.

For current guidance, return to the [documentation index](../README.md).
For publication status, use the [readiness audit](../maintainers/release-readiness.md).

The records are kept for traceability and are intentionally excluded from the
public-guide contract checks. New transient session logs should stay in local
ignored output or the issue tracker rather than extending this archive.
