# WidgetRail documentation

Start with what you want to do. You do not need to understand the renderer or
process architecture to use WidgetRail or write your first widget.

## Use WidgetRail

1. [Install and get started](users/getting-started.md)
2. [Learn the controls](users/controls.md)
3. [Pin video and compact widgets](users/pinning.md)
4. [Customization and widget management](users/customization.md)

Need help? Read [Troubleshooting](users/troubleshooting.md) or
[Compatibility and limitations](users/known-limitations.md).

## Build a widget

Start with [Your first widget](developers/widget-quickstart.md). Then follow the
[authoring guide](developers/widget-authoring-guide.md) at your own pace:

| Learn | You'll understand |
|---|---|
| [Core concepts](developers/concepts.md) | Widgets, views, actions, the host, and packages |
| [State and updates](developers/widget-model.md) | How an action changes what people see |
| [Navigation and scrolling](developers/navigation.md) | Focus IDs, shortcuts, routes, and paged collections |
| [Styling and themes](developers/styling.md) | How your widget fits the user's theme |
| [Loading data and lifecycle](developers/data-and-lifecycle.md) | When to fetch, refresh, and stop background work |
| [Media and pinned layouts](developers/media-and-pinning.md) | Videos, compact views, and live window previews |
| [Package and share](developers/publishing-and-installation.md) | How to distribute a widget for manual installation |

Explore [SDK Gallery](../samples/SdkGalleryWidget/README.md),
[Playnite](../samples/PlayniteLibraryWidget/README.md),
[Spotify](../samples/SpotifyWidget/README.md), and
[YouTube](../samples/YouTubeWidget/README.md) for complete examples.

[WRSS properties](reference/wrss.md), [capabilities](reference/capabilities.md),
